# Reading List CSV Exporter

A simple Chrome extension that exports your Reading List to a CSV file.

## Installation

1. Clone this repository.
2. Open `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the cloned repository folder.
6. To update the extension, pull the latest changes from the repository and click **Reload ⭮** on the extension in `chrome://extensions`.

## Usage

1. Click the extension icon.
2. Choose where to save the CSV file.
3. Done.

## Data Collection / Privacy

- The extension DOES NOT collect any data.
- No network requests are made.
